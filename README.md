## 🎨 Design & Inspiration

The entire visual identity and user interface for NVRLND was originally conceptualized and designed in **Figma**. We focused on dark-mode aesthetics, aggressive typography, and a seamless flow from product discovery to checkout.

Check out the full design case study here:  
👉 **[NVRLND on Behance](https://www.behance.net/gallery/249882351/NVRLND)**

## 💻 Tech Stack

This storefront was built for speed, smooth animations, and top-tier developer experience using modern web technologies:

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion (motion/react)
- **UI Components:** Radix UI primitives & Lucide Icons
- **Routing:** React Router

## 🛠 Platform Replicability

While this repository is a custom React implementation, the NVRLND design system and architecture are highly flexible. You can easily replicate and build this exact site experience using your favorite no-code/low-code or e-commerce platforms:

- **Framer** (for high-fidelity animations and rapid deployment)
- **Webflow** (for CMS-driven collections and precise visual development)
- **Shopify** (for heavy-duty e-commerce and inventory management)
- **WordPress / WooCommerce** (for maximum customization)
- **Kajabi** (for integrated digital product and course offerings)

## 🚀 Running the Code Locally

Want to spin up the local development server? 

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173/` in your browser.
